# Windows File Share & Permissions Lab

## Project Overview

This project simulates an enterprise file sharing environment. The lab provides hands-on experience with file shares, NTFS permissions, and access troubleshooting in an Active Directory environment.

The environment includes:

- Windows Server 2022
- Active Directory Domain Services (AD DS)
- NTFS and SMB file sharing
- Access troubleshooting and permissions testing

---

## Technologies Used

- Windows Server 2022
- Windows 10/11 clients
- Active Directory Domain Services
- NTFS and SMB File Sharing
- PowerShell
- Remote Desktop Protocol (RDP)

---

## Lab Architecture

| Resource | Purpose |
|---|---|
| File-Server | Shared folders and permissions |
| Client-1 | Domain-joined workstation |
| helpdesklab.local | Internal Active Directory domain |
